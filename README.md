# 🚀 星際打磚塊｜Neon Breaker Arcade

一款以星際霓虹風格打造的網頁打磚塊遊戲。移動擋板接住球、擊碎所有磚塊，挑戰更高關卡與最高分數！

遊戲以 **HTML、CSS 與原生 JavaScript** 製作，不需要安裝套件或建置工具，開啟 `index.html` 就可以遊玩。

## ✨ 遊戲特色

- **霓虹宇宙介面**：深色星空背景、發光磚塊與球體軌跡。
- **逐關挑戰**：清除所有磚塊即可進入下一關；隨關卡提升，磚塊排列與耐久度也會變化。
- **四種道具**：分身球、加寬擋板、加速球、慢速球。
- **多種操作方式**：支援鍵盤、滑鼠及觸控操作。
- **遊戲狀態控制**：可開始、發球、暫停、繼續及重新開始。
- **音效開關**：透過 Web Audio API 產生遊戲音效，可隨時切換靜音。
- **最高分紀錄**：使用瀏覽器 `localStorage` 儲存個人最高分，重新開啟網頁仍可保留（同一瀏覽器與裝置、未清除資料的情況下）。
- **響應式排版**：介面會依螢幕寬度調整，適合桌機與行動裝置瀏覽。

## 🎮 操作方式

| 操作 | 功能 |
| --- | --- |
| `←` / `→` | 左右移動擋板 |
| `A` / `D` | 左右移動擋板 |
| 滑鼠移動 | 控制擋板位置 |
| 觸控移動 | 控制擋板位置 |
| `Space` | 開始遊戲、發球或暫停／繼續 |
| `P` | 暫停／繼續遊戲 |
| 畫面上的按鈕 | 開始、發球、繼續或重新開始 |
| 「♫ 音效」按鈕 | 開啟／關閉音效 |

> 使用觸控裝置時，也可以在待發球狀態下點擊遊戲畫面發球。

## 🧩 道具介紹

| 道具 | 圖示 | 效果 |
| --- | :---: | --- |
| 分身球 | `×2` | 增加場上的球數，提升清除磚塊的效率。 |
| 加寬擋板 | `↔` | 擴大擋板寬度，更容易接球。 |
| 加速球 | `»` | 提高球的移動速度。 |
| 慢速球 | `«` | 降低球的移動速度，更容易控制。 |

擊破部分磚塊時有機會掉落道具，移動擋板接住即可觸發效果。

## 🏆 遊戲規則

1. 開始遊戲後按下發球按鈕或 `Space`，讓球開始移動。
2. 使用擋板反彈球，擊破畫面上的所有磚塊。
3. 清除全部磚塊後進入下一關，並獲得 **1 分**。
4. 球全部掉出畫面時失去一條生命；每局開始有 **3 條生命**。
5. 生命歸零時遊戲結束，可以選擇重新挑戰。

> 本遊戲目前以**通過關卡**累積分數，並非每擊破一塊磚塊就得分。

## 🚀 如何執行

### 方法一：直接開啟

1. 下載或複製此專案。
2. 使用瀏覽器開啟 `index.html`。
3. 點擊「開始遊戲」，再按「發球」開始挑戰。

### 方法二：使用 Git Clone

```bash
git clone <你的 GitHub 儲存庫網址>
cd <你的專案資料夾>
```

接著在瀏覽器開啟 `index.html` 即可。

此專案**不需要 `npm install`**，也不需要後端伺服器。網頁字型使用 Google Fonts，若要顯示指定字型則需要網路連線。

## 💾 最高分儲存方式

遊戲會將最高分保存在目前瀏覽器的 `localStorage` 中，使用的儲存鍵值為 `neonBreakerBest`。

- 不需要註冊或登入。
- 紀錄不會自動同步到其他電腦或瀏覽器。
- 清除網站儲存資料後，最高分可能會被重設。
